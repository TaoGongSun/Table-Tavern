## 狀態更新協定 v1（這桌的數值由系統保管）

數值由系統本地計算與記帳，你只要說「這一幕變動了多少」。每次回覆的最後附上更新區塊：

<UpdateVariable>
<JSONPatch>
[
  { "op": "delta", "path": "/Heroes/亞瑟/Affection", "value": 5 },
  { "op": "replace", "path": "/World/Location", "value": "晨港碼頭" }
]
</JSONPatch>
</UpdateVariable>

- path 用 `/` 分層，只寫這一幕真的變動的欄位，沒變的不要寫。
- 數字欄一律用 delta 給增減量（例 5、-10），不要給絕對值——給絕對值會被系統擋下。
- 「現值/上限」欄（例 "480/500"）：delta 動現值；只有上限改變（升級）才用 replace 寫成 "480/600"。
- 文字欄用 replace 寫新值；新增項目用 insert、刪除用 remove、搬移用 move。
- 骰值欄由系統每回合擲，你只讀不寫。
- 上下限與拒收由系統把關，被擋下的欄位會在下一輪告訴你目前值。

Affection 每回合必報。

本桌的更新區塊長這樣（路徑照本桌狀態樹；不要照抄上面通用協定範例裡的 /Heroes、/World 路徑）：
<UpdateVariable>
<JSONPatch>
[
  {"op":"replace","path":"/Heroes/*/Mood","value":"（新的值）"},
  {"op":"delta","path":"/Heroes/*/Affection","value":-1}
]
</JSONPatch>
</UpdateVariable>
