# room-player-cards — 多人房間階段二：玩家匯入／編輯自己的卡

Status: done

## Summary
手機玩家可以匯入卡檔（只收名字、公開段與顯示圖）、用「建立角色」自建，入座後用「編輯我的角色」改名字、圖示、公開描述與秘密情報，也能換角色圖（上傳或 AI 生圖）。秘密情報只經過房間伺服器的記憶體，存在房主電腦，GM 提示詞的「玩家角色」段帶它和不得揭露的句子；單人桌的玩家卡也有這一欄。房間生圖只走 API：本機生圖來源不是 API 時，桌面不顯示開關、手機不顯示生圖段。規格、協定、實作差異與觀察見[方案檔](../../plans/room-player-cards.md)。

驗證：verify 16 步綠。測試通道方案 §7 的 11 步都過；房間生圖誘導測試（來源設 agy、codex、grok）在呼叫前就被拒；夾心字串跳不出資料區塊（實機抓的提示詞確認）。
