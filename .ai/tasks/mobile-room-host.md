## Summary
現在開房只能用桌面版，因為房主那台 App 要做三件事：用 CLI 呼叫模型、當 GM 主機（組提示詞、解析回覆）、存桌面資料。改用 API 就不需要 CLI，但 GM 主機和存檔也得跟著換地方。目標是讓 Android 玩家直接用手機開房〔作者 2026-11-06 提出，不急著開工〕。

## 方向（2026-11-06 討論，〔模型判斷·未裁決〕）
- 主機放房主手機（listen server），不搬到我們的伺服器，所以金鑰和存檔都不交給我們。
- APK 用 Android 前景服務撐住背景執行，這是網頁版做不到的地方；房主切出 App 或鎖螢幕，房間照常跑。房主手機斷線就整桌停，這點跟現在用桌面版開房一樣。
- 金鑰入口有兩條：OpenRouter OAuth 一鍵授權為主；國產模型走手動金鑰為輔，App 內開申請頁、偵測剪貼簿裡的金鑰並打一發驗證。另外可加桌面掃 QR 把金鑰帶到手機。
- 桌面版照舊用 CLI 開房，門檻不變；手機開房是多給一條路。
- 這幾條不能走：借用 Claude／ChatGPT 訂閱的登入憑證（違反條款，會害玩家被封號）；我們代收費、代付 API（等於改商業模式）。

## 評估要回答
- 能不能疊在 [cn-apk-shell](cn-apk-shell.md) 的 Capacitor 殼上：`web/` 已經有 API 供應商路徑和 MVU 引擎，房間 GM 迴圈（目前在 `src-tauri` 的 room/run.rs）要搬多少到網頁端。
- 前景服務在主流國產 ROM（小米、華為、OPPO、vivo）能撐多久，要不要引導玩家加電池白名單。
- 中國玩家能不能在 OpenRouter 儲值。

## 已知限制
- iOS 不允許 App 長時間在背景跑，iPhone 只能當一般座位。
