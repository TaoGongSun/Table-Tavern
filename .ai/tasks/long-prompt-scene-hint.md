# 桌子太長撞到指令長度上限時，請玩家換幕

## Summary

CLI 三條路把整包 prompt 放進命令列參數（grok 的 `-p`、codex／agy 同理），桌子夠長就會撞到作業系統的指令長度上限（macOS 約 1MB），那一輪整個呼叫失敗。實測 2026-08-22 帳本有一列 241,336 tokens、約 700KB，已經很接近。

不做「改走檔案傳 prompt」那條（要動生圖、翻譯、卡重構全部通道，還要處理暫存檔生命週期）。只要抓出這個錯誤類型，在聊天室錯誤列給一句「這桌太長了，換一幕再繼續」的人話。

## Next action
