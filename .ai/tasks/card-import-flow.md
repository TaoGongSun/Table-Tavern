## Summary
匯入卡的流程整修（2026-08-04 兩輪拍板）：一顆按鈕進、問不問看檔案內容；每次匯入記收據可一鍵倒退；第二張卡跳「開新桌？」路由框治「忘了開新桌」誤按，雙世界書硬擋；卡名自動當桌名；世界書匯入後目標一律指 GM。AI 重構按鈕另案（等狀態欄二期真桌實跑後細拍）。

## 拍板結論
1. **類型判定看檔案結構，判準只影響預選**：檔案無角色欄位（缺 name）＝純世界書檔，直接走世界書路徑（修掉現況：這種檔丟主按鈕報「角色卡缺少 name」）；有 name 無 character_book 條目＝純角色卡，直接走角色路徑；兩邊都有料＝跳選擇框「角色卡（角色與附帶設定都進來）／只要世界書（不建角色）」，用 lorebook_heavy 預選。舊的兩鍵確認框（importLorebookRedirect，按取消整次作廢）刪除。
2. **GM 編輯世界書區移除「匯入世界書」按鈕**，保留新增條目、去重、匯出。匯入入口只剩側欄一顆。
3. **匯入收據＝復原地基**：每次匯入記實際新增的東西（身分 character/worldbook、角色 id、世界書條目 uid、機制新增、桌名是否被這次改過），一鍵倒退整筆拿掉、可連按逐筆退。去重時本來就存在的條目不動；復原時玩家改過內容的條目跳過不刪＋回報保留數（防資料遺失）；聊天訊息不動。
4. **第二張卡路由框**：桌上已有匯入紀錄（看收據）再匯 → 三選框「開新桌並匯入（主按鈕）／匯進這桌／取消」，文案零說教。雙世界書（新檔走世界書身分＋桌上已有世界書身分收據）→「匯進這桌」封死。配套例外：新檔是純世界書 JSON 且桌上世界書身分收據為零 → 不跳框直接匯。手建角色不算匯入紀錄。
5. **卡名→桌名**：開新桌並匯入直接用卡名（純世界書檔用檔名去副檔名）；匯進還掛自動名的桌（沿用 reclaimIfUntouched 的自動名判斷）也自動改；使用者自訂過名的桌不動。復原時桌名一併改回。
6. **世界書匯入後一律 setSpeaker(GM)**：兩條路徑（GM 編輯區、選擇框世界書分支）都改，現況只有零角色才指。
7. 第二張角色卡零說教零警告（路由框即誤按攔截）；衝突善後交給收據復原。
