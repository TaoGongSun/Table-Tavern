狀態規則：仍需程式施工／規格落地＝「進行中」；施工已完成、只剩可執行環境／使用者實機／外部條件驗收＝「等實機驗收」，並列入實測佇列。驗收通過後才結案封存。

現行 handoff 結案後移至 [handoffs/archive/](handoffs/archive/)；以下為舊 CLI 時代的存檔，凍結只讀：[已完成任務](DONE.md)、[每日活動紀錄](history/)。
