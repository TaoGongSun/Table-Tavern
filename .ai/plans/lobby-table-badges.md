# lobby-table-badges 規格

本檔存放 [lobby-table-badges](../handoffs/lobby-table-badges.md) 的規格與驗收。

## 定案
1. **釘頂**：`activeRoom` 那張桌排牆的第一張，其餘維持後端的最後活動排序。封面左上色帶顯示「房間中・房間碼 XXXX」（沿用 `table-cover-ribbon` 一條色帶，新 `data-state="room"`；與 VN 的撰寫中／設定未完成色帶同位置，房間中優先）。
2. **篩選籤**：牆標題列下方一排籤「全部／聊天／VN／開過房」。桌數（含所有桌）少於 8 張整排不渲染；8 張以上才出現。籤是篩選不是分頁：選中後只隱藏不符的卡，釘頂規則仍適用；選擇不持久化，重開 app 回「全部」。「聊天」＝`table_kind === "chat"`；「VN」＝`table_kind === "vn"`（含作品）；「開過房」＝`world.id in rooms`。〔模型判斷·未裁決〕
3. **入口卡**：維持四張、各自一鍵進流程（收成三張會替最常用的建桌多一步）。順序改成：開新的一桌、一句話開桌、視覺小說、和朋友一起玩（開房）。開房卡標題文案改成意圖式「和朋友一起玩」，副標維持現有說明；房間開著時仍顯示「回房間」。〔模型判斷·未裁決〕
4. **擴充規則**寫進 [docs/STRUCTURE.md](../../docs/STRUCTURE.md) 大廳段（沒有就新增一小段）：新的遊玩畫面才加 `table_kind` 與一枚籤；新的玩法（開房、觀戰）是卡上的徽章與動作；新的內容能力（規則書、擲骰、狀態欄）靠內容偵測自動掛上，不進大廳分類。
5. **不做**：跑團徽章、「帶規則書」選項（等 ttrpg-rules-system v1）；單人／多人分區。

## 驗收
- 房間開著時該桌排第一且帶「房間中・房間碼」色帶；關房後回原位、色帶消失。
- 7 張桌無篩選籤；8 張出現；切「VN」只剩 VN 桌，釘頂的房間桌若非 VN 則隱藏；切回「全部」恢復。
- 入口卡順序與文案如定案 3，十一語系鍵齊全（`npm run verify` i18n 關卡綠）。
- `npm run verify` 全綠；Lobby／TableCard 測試蓋釘頂、門檻、篩選三件。
- 測試通道截圖：大廳有房間開著、8 張桌以上有籤、切籤後；主線親看。
