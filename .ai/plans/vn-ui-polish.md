## 2 包 A：結構與推進

### 2.1 版面改成疊層
- `.vn-stage` 改 `position:absolute; inset:0`，背景鋪滿整個播放器；`.vn-bottom`（選項、對話框、快捷列）疊在底部；工具列拿掉。
- 立繪 `bottom:0`、高度＝播放器高的 92%×比例（包 B 再調比例與槽位）；下緣自然被對話框蓋住，不再用 `bottom:-12%` 裁。
- 對話框維持 `--vn-box` 0.88 透明、最大高 38vh。

### 2.2 推進入口
- 點擊：`.vn-stage` 與 `.vn-bottom` 空白處都等於點對話框（`onAdvance`）。選項面板開著時點舞台不動作；`play.end === "chapter"` 時點擊＝進章末流程（與自動流程一致，不另確認）；`play.end === "continue"` 仍只靠「繼續」鈕（會花玩家額度，不讓誤點觸發）。
- 鍵盤（`VnPlayer` 掛 `window` keydown／keyup，標題、面板、紀錄、字卡、完結蓋著時不處理；目標是 input／textarea／select 或對話框以外的按鈕時不處理；對話框按鈕本身 preventDefault 免得原生 click 再推一次）：
  - Space、Enter、→、↓、PageDown＝推進；←、PageUp、Backspace＝上一格
  - 按住 Ctrl＝快進（keydown 開、keyup 關；放開回到原本的快進開關狀態）
  - Esc＝開遊戲選單（有面板或紀錄開著＝先關它）；A＝自動開關；H＝隱藏介面
  - 面板（存檔、設定、結局、章節、選單）Esc 一律可關；紀錄已有。
- 滾輪：往上＝上一格（照舊）；往下＝推進，同一個 250ms 節流。
- 右鍵（`contextmenu` 於 `.vn-player`，preventDefault）＝開遊戲選單。
- 隱藏介面（H 或選單項「隱藏介面」）：`.vn-bottom` 整塊隱藏，任一點擊、任一鍵恢復；auto／skip 照跑。

### 2.3 快捷列與遊戲選單
- 快捷列（`.vn-quick`）貼在對話框正下方、靠右一行小字（`--fs-ui`、半透明、按下亮琥珀）：上一格｜自動｜快進｜紀錄｜存檔｜設定｜選單。生成中在最左多一顆「停止」（紅字）。重播桌一樣七顆。
- 遊戲選單（`panel === "menu"`，用現有 `Panel` 樣式）：桌名當標題；按鈕直列：回標題、存檔與讀檔、設定、結局一覽、從某一章重玩（重播桌＝章節選擇）、下一章（非重播，照原本 `askNextChapter` 確認）、聊天視圖（非重播）、重生成背景（非重播、有背景時）、匯出成 VN 卡（非重播）、匯出 VN 作品（非重播）、隱藏介面、回大廳、關閉。
- `VnToolbar.tsx` 與其 `MoreMenu` 用法刪除；`ErrorNote` 改疊在頂部置中（z 高於舞台）。
- 設定面板從遊戲中也能開（快捷列「設定」）。

### 2.4 標題與進桌位置
- 標題鈕：沒進度（`progress.positions` 空且沒有存檔）＝開始（primary）、結局一覽、設定、回大廳；有進度＝繼續（primary）、開始（重玩確認照舊）、讀檔、結局一覽、設定、回大廳。有存檔但沒進度時加「讀檔」。
- 標題開設定／讀檔／結局一覽：面板 z-index 高於標題（標題 4 → 面板 5），標題不消失，關閉回標題；標題上「讀檔」開的面板標題文字為「讀檔」。
- 沒進度的進桌位置：改成幕首第一個可停格（`entryKey` 改為 `start` 語意；有 `resumeKey` 或 `entry` 時照舊）。有進度檔的桌不受影響。

### 2.5 紀錄
- 打開時捲到最底（`scrollTop = scrollHeight`）；字級跟對話框同（`--fs-story`）。

### 2.6 隨視窗縮放
- `.vn-player { container-type: size }`；對話框字級 `clamp(1rem, 2.4cqh, 1.8rem)`、名牌與選項同步；對話框寬 `min(92%, 64rem)` 改 `min(92%, 110cqh)`（高越大框越寬，1600×900 約 990px，字約 21.6px）；快捷列字級 `clamp(0.75rem, 1.6cqh, 1rem)`。

### 2.7 包 A 驗收
- 單元測試：鍵盤對應（含面板開著不處理、Ctrl 放開還原）、沒進度進桌落幕首、標題鈕依進度切換、紀錄開啟捲底。
- 測試通道重播桌：點舞台推進、Esc 開選單、右鍵開選單、H 隱藏、滾輪下推進、標題「開始」落幕首、設定疊在標題上、1600×900（`html{zoom:.5}` 模擬）字級變大。截圖主線親看。
- `npm run verify` 綠。

## 3 包 B：舞台與細節

### 3.1 立繪
- 槽位：單人在台＝中央槽；兩人＝左、右；三人＝左、中、右（進場順序照舊決定誰拿哪個槽，只改「獨自一人時站中間」）。換槽用既有 `left` 過渡。
- 比例：`--vn-scale` 下限 0.7（名單最高者＝1）。
- 非說話者 `brightness(0.7) saturate(0.85)`；說話者 `scale(1.02)`、不再 `translateY`。
- 特寫：以臉框為錨放大約 1.7 倍、臉落在舞台上 1/3；用人偶素材調到頭頂不出畫、肩線在對話框上方。

### 3.2 地點字卡
- 換 `[bg]` 時出現 4 秒後淡出（`prefers-reduced-motion` 直接消失）；只顯示地點、不顯示時段。

### 3.3 選項
- 字級與對話框同、`--font-story`、置中；寬 `min(36rem, 90%)`。
- 重播桌過去的選項面板標目前路線（`vn-choice-current`）；未走過的選項框不透明、只壓文字（`opacity` 改文字 `color` 淡）。

### 3.4 章末
- 字卡蓋著時 `paused`（打字、auto、skip 停）；「尾聲」誤判：`nextChapter` 只在新幕格已載入（`vn.formalScene === 新幕`）才算，否則不顯示標題行。
- 重播桌章末格沒有下一幕時跳過該格（游標推進時當成不可停）。

### 3.5 細項
- 完結畫面主鈕「回標題」，章節選擇／結局一覽次之。
- 獨白：去斜體、保留淺藍、文字前後加（）。
- 無立繪剪影 `opacity: 0.35`。
- 標題「讀檔」面板標題「讀檔」（§2.4 一併）。

### 3.6 包 B 驗收
- 通道用人偶素材：單人置中、三人同台、特寫、字卡淡出、選項字級、章末字卡期間不打字。截圖主線親看。verify 綠。
