# Table Tavern（桌面酒館）

**[English →](README.md)**

一款桌面 App：AI 扮演一整桌角色，連 GM（主持人）也是 AI。

想玩多簡單、多深都行：丟一張角色卡進來就能直接對話；也可以開一張完整的桌——世界設定、世界書、換幕、由 GM 旁白並決定誰接話。每個角色只知道 GM 說出口的內容，祕密在劇情揭露之前就是祕密——一般 AI 對話得靠 AI「假裝不知道」來守密，這裡的角色是真的不知道。

介面支援十國語言（繁中、简中、英、日、韓、西、葡〔巴西〕、德、法、俄），內建範例桌會跟著你的語言走，切換語言後也能一鍵重產。

## 下載與安裝

> 目前提供的是**測試版**，還有粗糙的地方。歡迎把任何使用感受與建議丟到 [GitHub Issues](https://github.com/TaoGongSun/Table-Tavern/issues)——每一則回饋都在幫忙打磨這款遊戲。

**Windows**：從發佈頁下載安裝檔。Windows 可能顯示「未知的發行者」——點「其他資訊 → 仍要執行」。

**macOS**（Apple Silicon）：下載 `.dmg`，把 `Table Tavern.app` 拖進「應用程式」，雙擊開啟。

如果系統說「無法驗證是否為惡意軟體」：按「完成」，開「系統設定 → 隱私權與安全性」，捲到最底下按「仍要打開」，再確認一次就好。會跳這個警告只是因為測試版還沒送 Apple 公證，不是中毒。

## 開始玩

1. 第一次開啟會直接進到範例桌，隨便逛沒關係。
2. 要讓角色開口，App 需要接一個 AI 服務。標準做法：註冊 [OpenRouter](https://openrouter.ai/)，儲值小額，把 key 貼進畫面上的引導欄位。一把 key 通吃多家模型，GM 和每個角色還能各用不同檔位。用多少付多少，沒有月費。
3. 這樣就好。寫一張卡，上桌，開玩。

已經有訂閱 Claude、ChatGPT、Gemini 或 Grok？可以改走官方命令列工具、直接花訂閱額度——見下面 Q&A。

## 常見問題 Q&A

**這個 App 要錢嗎？**
免費且開源。唯一的花費是 AI 供應商按用量收的錢，由你直接付給他們。

**我可以贊助嗎？**
**現在還在測試期間，請不必贊助。**贊助回禮（五套佈景配色、AI 角色圖生成）已經做好，現在贊助就能解鎖；只是整體體驗還在打磨，這個階段先不好意思開口收錢。

**我的對話會被上傳到哪裡嗎？**
不會。桌、角色卡、對話紀錄全是你電腦裡的純文字檔，API key 也只存在本機。對話直接從你的電腦送到你選的 AI 供應商，中間沒有任何自營伺服器。

**可以用 SillyTavern 的角色卡嗎？**
可以。V2 角色卡 PNG 直接匯入，你的卡也能匯出成 PNG 或 JSON 帶走。

**角色會不會「偷看」到不該知道的設定？**
不會。只有 GM 讀得到世界設定和所有人的卡。角色要等 GM 在劇情裡實際說出來才會知道；世界書條目還能指定只給特定角色看。

**我已經有訂閱 Claude／ChatGPT／Gemini／Grok，能直接用嗎？**
可以——在 AI 設定把傳輸方式切成該家的官方 CLI（內建一鍵安裝）。各家對這種用法的政策不同、也會變動；啟用前 App 會顯示該供應商的風險說明，由你自己判斷。

**資料存在哪？怎麼備份？**
全部在「文件/TableTavern/」資料夾——複製這個資料夾就等於備份了所有桌、卡和紀錄。設定與 key 存在系統的應用程式設定資料夾，和你的故事分開放。

**App 打不開／被系統擋下？**
見上面安裝那節——那是未簽章測試版的標準警告，不是掃到病毒。

## 給開發者

Tauri 2（Rust）＋ Vite + React + TypeScript。產品規格見 `NewPlan.md`，工程起手見 `KICKOFF.md`，版本異動見 [CHANGELOG.md](CHANGELOG.md)。

```bash
npm install
npm run tauri dev    # 開發模式
npm run tauri build  # 產出 .app／DMG／安裝檔
cd src-tauri && cargo test
npm run build        # 前端型別檢查＋建置
```
